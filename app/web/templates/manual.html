Passo a passo (lote por planilha)

Siga esta ordem para evitar erros comuns.

  1. Baixe o template (XLSX recomendado): use os links abaixo.
    Baixar XLSX Baixar CSV
  2. Preencha as colunas e mantenha o arquivo com extensão .xlsx ou .csv.
  3. Envie a planilha na tela inicial e informe um CEP padrão.
  4. Clique em "Executar planilha" e aguarde o processamento do lote.
  5. Acompanhe o progresso abrindo o lote (ele fica disponivel em "Pesquisas recentes").
  6. Exporte os resultados baixando o arquivo .xlsx ao finalizar.

Execução por base salva

Use este modo para rodar todos os produtos importados contra todos os CEPs da base local.

  1. Garanta que a base foi gerada em artifacts/base_frete.db com os scripts de importação.
  2. Na home, abra a seção Executar base salva.
  3. Selecione os links/produtos e os CEPs desejados, ou rode a base completa.
  4. Confira os totais exibidos (produtos, CEPs e total previsto de execuções) e inicie o lote.

Central de resultados

A qualquer momento, use o botao resultados no topo para abrir, revisar e baixar os dados gerados.

Agendamento automatico

Na home, use a area Pesquisa automatica por agendamento para criar execucoes diarias em horario fixo.

O agendamento usa o horario local do servidor e pode rodar a base completa ou uma selecao personalizada de produtos e CEPs.

Template e regras

Regras do arquivo e formato esperado das colunas.

Arquivo com extensão .xlsx ou .csv
Campo Link do produto preenchido
CEP por linha é opcional (usa CEP padrão quando vazio)
Colunas aceitas: Grupo, Nome do produto, ID do produto, Link do produto, CEPs para testar.
Dica: no campo CEPs para testar, use 1 ou mais CEPs separados por vírgula. Se deixar vazio, o sistema usa o CEP padrão.

Problemas comuns

Solução rápida para os erros que mais aparecem.

"Envie a planilha (.xlsx ou .csv)"
Selecione um arquivo válido e confirme a extensão (xlsx/csv).
"Planilha sem linhas válidas"
Verifique se existe ao menos 1 linha com Link do produto preenchido.
Resultados faltando
Abra o lote e veja se ainda há itens em execução ou na fila.
CEP invalido
Use formato 00000-000 ou só números. O sistema normaliza automaticamente.
